# LazoDiscs

Burn supported music links onto vanilla music discs and play them from jukeboxes through Plasmo Voice positional audio.

## Features

- Burn YouTube, YouTube Music, SoundCloud, Spotify track links, and direct playable audio URLs onto music discs.
- Search for songs in chat and burn tracks from clickable results.
- Set a custom title, volume, and playback range for a disc.
- Play custom discs from jukeboxes with positional audio.
- Works with Sable and Create Aeronautics moving platforms where the corresponding game version and loader are supported.

Commands: `/lazodisc burn <url> [title]`, `/lazodisc erase`, and `/lazodisc search <song name>`. Search is for song names; use `burn` for a URL. Spotify links are matched to playable audio through YouTube Music when a match is available.

## Installation

All builds require Plasmo Voice. Fabric builds also require Fabric API.

For multiplayer, install LazoDiscs and Plasmo Voice on the server. Players need Plasmo Voice on their clients to hear the music. Installing LazoDiscs on a client is optional; it improves custom-disc tooltips by hiding the vanilla song description and leaving the custom title.

For singleplayer, install LazoDiscs and Plasmo Voice in the game instance. Fabric builds also require Fabric API.

## Supported versions

Release builds follow stable Plasmo Voice 2.1.17 support. The Minecraft versions with at least one build are:

`1.16.5`, `1.17.1`, `1.18.2`, `1.19`–`1.19.4`, `1.20`–`1.20.4`, `1.21`, `1.21.1`, `1.21.4`, `1.21.6`–`1.21.8`, `1.21.11`, and `26.1`–`26.3`.

Loader availability varies by exact Minecraft version. Choose the matching file from the [GitHub releases](https://github.com/EyeCrasher07/LazoDiscs/releases), [Modrinth](https://modrinth.com/mod/lazodiscs), or [CurseForge](https://www.curseforge.com/minecraft/mc-mods/lazodiscs).

## По-русски

LazoDiscs позволяет записывать ссылки на музыку на обычные пластинки Minecraft и слушать их в проигрывателях через позиционный звук Plasmo Voice.

### Возможности

- Запись ссылок YouTube, YouTube Music, SoundCloud, треков Spotify и прямых ссылок на аудиофайлы на пластинки.
- Поиск песен в чате и запись трека из интерактивных результатов.
- Настройка названия, громкости и радиуса воспроизведения пластинки.
- Воспроизведение пользовательских пластинок в проигрывателях с позиционным звуком.
- Поддержка движущихся платформ Sable и Create Aeronautics в тех версиях и загрузчиках, где доступна соответствующая совместимость.

Команды: `/lazodisc burn <ссылка> [название]`, `/lazodisc erase` и `/lazodisc search <название песни>`. Команда `search` ищет песни, а для ссылки используй `burn`. Ссылки Spotify сопоставляются с доступной версией трека на YouTube Music.

### Установка

Для всех сборок нужен Plasmo Voice. Для Fabric также нужен Fabric API.

В мультиплеере установи LazoDiscs и Plasmo Voice на сервер. Игрокам нужен Plasmo Voice на клиенте, чтобы слышать музыку. LazoDiscs на клиенте необязателен, но улучшает подсказки к пластинкам: вместо стандартного описания Minecraft будет отображаться только пользовательское название.

В одиночной игре установи LazoDiscs и Plasmo Voice в клиентский экземпляр Minecraft. Для Fabric также нужен Fabric API.

### Поддерживаемые версии

Релизные сборки соответствуют стабильной поддержке Plasmo Voice 2.1.17. Хотя бы одна сборка есть для версий Minecraft:

`1.16.5`, `1.17.1`, `1.18.2`, `1.19`–`1.19.4`, `1.20`–`1.20.4`, `1.21`, `1.21.1`, `1.21.4`, `1.21.6`–`1.21.8`, `1.21.11` и `26.1`–`26.3`.

Наличие сборки для конкретного загрузчика зависит от версии Minecraft. Выбирай подходящий файл на [GitHub](https://github.com/EyeCrasher07/LazoDiscs/releases), [Modrinth](https://modrinth.com/mod/lazodiscs) или [CurseForge](https://www.curseforge.com/minecraft/mc-mods/lazodiscs).
