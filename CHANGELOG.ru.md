# История изменений LazoDiscs

## [1.0.7] - 2026-10-13

### Исправлено

- При записи пластинки по ссылке Spotify сохраняется ссылка на выбранную аудиозапись: повторное воспроизведение больше не повторяет поиск Spotify. Подбор Spotify теперь отклоняет посторонние названия, даже если длительность близка.
- Исправлено воспроизведение SoundCloud с потоками AAC/fMP4 HLS, включая короткие ссылки on.soundcloud.com; поддержка прежних аудиоформатов сохранена.
- Восстановлено воспроизведение записанных пластинок в Sophisticated Backpacks на Fabric с новым API SoundHandler в SophisticatedCore. Вместо исходной песни Minecraft играет записанный трек.
- Сохранена поддержка прежнего API обработчиков пластинок SophisticatedCore на Forge и NeoForge, включая версии, где остановка принимает серверный мир.
- Сохранена корректная очистка воспроизведения и обработка завершения трека при остановке, замене и окончании записи в рюкзаке.

### Изменено

- Из релизных файлов удалён устаревший YouTube-модуль LavaPlayer с кодом передачи данных Google-аккаунта стороннему серверу. Воспроизведение и поиск YouTube продолжают работать через youtube-source.
- Остальные источники LavaPlayer регистрируются явно; поддержка SoundCloud и прямых аудиоссылок сохранена.

Набор из 52 сборок Minecraft/загрузчиков и публичные интерфейсы для LazoBoombox сохранены. Нужен Plasmo Voice; для Fabric также нужен Fabric API.

## [1.0.6] - 2026-10-07

### Добавлено

- Добавлена поддержка Forge.
- Добавлены сборки для большего количества версий Minecraft, начиная с 1.16.5, по поддержке стабильного Plasmo Voice 2.1.17. Всего 52 сборки: 25 Fabric, 15 Forge и 12 NeoForge.

### Исправлено

- Исправлена работа проигрывателя при установке и извлечении пользовательских пластинок на поддерживаемых версиях 1.21.x.
- Убраны лишние остановки и перезапуски музыки, когда попытка извлечения оставляет пластинку в проигрывателе.

### Изменено

- Иконка мода заменена на новое изображение 256×256 в меню модов и Plasmo Voice.
- Релизные сборки теперь следуют версиям Minecraft, которые поддерживает стабильный Plasmo Voice 2.1.17. Версии только для старых или beta-выпусков Plasmo Voice не включены.

Нужен Plasmo Voice. Для Fabric также нужен Fabric API.
